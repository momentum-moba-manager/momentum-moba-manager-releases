## What it is

Momentum is a management sim in the spirit of Football Manager, set in the professional League of Legends scene. You're the coach: pick a club, shape the roster, set the strategy for every series, and watch a full match engine play it out.

- **Real match simulation.** Laning, ganks, sieges, neutral objectives, and team fights play out on a simulated map, calibrated against real pro play.
- **Draft and tactics.** Ban/pick with Fearless Draft across Bo1, Bo3, and Bo5 series, plus six strategy dimensions per game.
- **A living world.** Every Tier 1 league runs its season around you, with international events and athletes who grow, peak, retire, and get replaced by new talent.
- **The business side.** Contracts, free agency, wages, sponsors, and prize money.

## Install

1. Click **Download for Windows** above. It always downloads the newest build.
2. Run `Momentum-MOBA-Manager-Setup-x64.exe`. It installs for your user only and doesn't need administrator rights.
3. **"Windows protected your PC"?** The installer isn't code-signed yet, so SmartScreen doesn't recognize it. Click **More info**, then **Run anyway**.

You don't have to check back for new versions: the game tells you on startup when a newer build is out.

**Requirements:** Windows 10 or 11, 64-bit. Microsoft Edge WebView2 is required, and the installer sets it up automatically if it's missing.

## Report a bug

1. **Open the game folder.** In a career, click the gear icon, then the **Game folder** button.
2. **Attach the log** from the `logs` folder: `game.log` is the current or last session. The game starts a new log every time it opens, so if you restarted after the bug, attach the newest `game_<date>.log` instead.
3. **Attach your save** from the `saves` folder if the bug happened in a career, so it can be reproduced from the same point.
4. **Say what you did** right before it happened, and what you expected instead.

**The game doesn't start?** Paste `%APPDATA%\com.mmm.moba-manager` into the File Explorer address bar to reach the same folder.
